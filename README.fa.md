## 📖 درباره

**ساهندسافت** یک کلاینت VPN اندرویدی با بازطراحی کامل است که روی هسته Xray
(`flutter_v2ray`) کار می‌کند. این نسخه بازسازی کامل رابط و تجربه کاربری پروژه
متن‌باز [BegzarApp](https://github.com/Begzar/BegzarApp) (مجوز MIT) است:
هویت بصری جدید، سیستم طراحی اختصاصی، فارسی‌محوری با پشتیبانی کامل RTL،
تم روشن و تاریک بر پایه Material 3 و لایه جدید مدیریت کانفیگ توسط کاربر.

## 📲 نصب (اندروید)

### روش ۱ — دانلود APK آماده از GitHub Actions
1. وارد مخزن شوید → تب **Actions** → **Build APK (SahandSoft)**.
2. آخرین اجرای موفق را باز کنید → بخش **Artifacts** → فایل **SahandSoft-APKs** را دانلود کنید.
3. فایل zip را باز کرده و `SahandSoft-universal.apk` را نصب کنید (یا APK متناظر با CPU گوشی؛ برای اکثر گوشی‌های جدید `arm64-v8a`).

### روش ۲ — ساخت خودتان
```bash
flutter pub get
flutter build apk --release
# build/app/outputs/flutter-apk/app-release.apk
```

> ℹ️ امضای نسخه release از طریق Secrets مخزن انجام می‌شود
> (`ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`).
> برای ساخت شخصی، یک keystore خصوصی بسازید و آن را در مخزن قرار ندهید.

## ⚠️ محدودیت‌ها و شفافیت

- **بک‌اند پروژه پایه در سورس عمومی وجود ندارد.** در مخزن اصلی BegzarApp، آدرس
  سرورِ ارائه‌دهنده کانفیگ‌های رایگان از کد حذف شده است (baseUrl خالی). بنابراین
  جریان «دریافت کانفیگ از سرورهای بگذر» با سورس عمومی اصلاً کار نمی‌کند.
  ساهندسافت این جریان را با لایه‌ای معادل و کاملاً کاربردی جایگزین کرده است:
  **کانفیگ را شما وارد می‌کنید** (لینک دستی یا اشتراک) و برنامه با همان موتور
  Xray و همان مسیر کد اتصال برقرار می‌کند. در هیچ‌جای برنامه داده ساختگی
  استفاده نشده است.
- **جریان بررسی آپدیت حذف شد.** دیالوگ آپدیت پروژه پایه به بک‌اند خصوصی بگذر
  وصل بود و برای این نسخه کاربردی ندارد.
- **فونت‌ها.** فونت‌های Gilroy و Dana تجاری هستند و برای رعایت مجوز بازتوزیع،
  از این نسخه حذف شدند. برنامه اکنون از **Shabnam** (مجوز SIL OFL 1.1)
  استفاده می‌کند.
- **نکته مجوز.** مخزن پایه همین درخت کد را با مجوز MIT منتشر کرده (فایل
  `LICENSE`)؛ هرچند README آن اعلام می‌کند توسعه از نسخه ۵.۵.۰ به بعد
  closed-source است. این نسخه بر پایه درختی ساخته شده که با MIT منتشر شده،
  اعلان کپی‌رایت اصلی حفظ شده و همه تغییرات مستند است.
- **دامنه تست.** در CI تحلیل، تست‌ها و build release اجرا می‌شود. رفتار واقعی
  VPN روی دستگاه (دیالوگ مجوز، چرخه عمر تونل) باید روی گوشی حقیقی بررسی شود —
  به محیط ساخت هیچ دستگاه یا شبیه‌سازی متصل نیست.
